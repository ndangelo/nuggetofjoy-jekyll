<!-- wp:paragraph -->
<p>The following tutorial will teach you how to edit text in Adobe Illustrator using various techniques.</p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-pqeg-how-to-edit-text-in-illustrator">1.&nbsp;How to Edit Text in Illustrator</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Using the&nbsp;<strong>Selection Tool (V)</strong>, simply&nbsp;<strong>double-click</strong>&nbsp;on the text to edit it.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText1-1.gif" alt="how to edit text in Illustrator using the Selection Tool"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>Using the&nbsp;<strong>Type Tool (T)</strong>, click on the text, and then you can edit it.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText2.gif" alt="how to edit text in Illustrator using the Type Tool"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>If you can't edit text in Illustrator, have a look at the&nbsp;<strong>Layers</strong>&nbsp;panel (<strong>Window &gt; Layers</strong>) and make sure that it's not locked.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>If you click your text and you can see an outline around the characters, it means that your text is turned into outlines (vector paths), making your text uneditable.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText2B.jpg" alt="when you can't edit text in Illustrator"/></figure>
<!-- /wp:image -->

<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-2cfj-how-to-further-edit-text-in-illustrator">2.&nbsp;How to Further Edit Text in Illustrator</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-ndte-step-1">Step 1</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Select some text and use any of the options on the&nbsp;<strong>Type</strong>&nbsp;panel (<strong>Window &gt; Type</strong>) to further edit text in Illustrator.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The&nbsp;<strong>Character</strong>&nbsp;panel (<strong>Window &gt; Type &gt; Character</strong>) is the main panel that you should master. Check out this tutorial to learn all that you need to know about the&nbsp;<strong>Character</strong>&nbsp;panel:&nbsp;<a href="https://design.tutsplus.com/tutorials/a-beginners-guide-to-the-character-panel-in-illustrator--cms-42092">A Beginner's Guide to the Character Panel in Illustrator</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText3.jpg" alt="edit text in Illustrator using Type panels"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-uoas-step-2">Step 2</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>As you would with any other vector shape, you can easily color and style text using basic fill and stroke settings. You can easily set these attributes using the&nbsp;<strong>Toolbar</strong>, the&nbsp;<strong>Control</strong>&nbsp;panel, or the&nbsp;<strong>Properties</strong>&nbsp;panel.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter" id="ie5zz"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText4.jpg" alt="edit text colors in Illustrator"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>Advertisement</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-7el8-step-3">Step 3</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Finally, you can further edit text in Illustrator using the Appearance panel (Window > Appearance). A bunch of well-placed fills, strokes, and effects can turn any text into a work of art.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText5.jpg" alt="edit text in Illustrator using the Appearance panel"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>And the neat thing about these techniques is that your text remains fully editable.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="http://nuggetofjoy.com/wp-content/uploads/EditText6.gif" alt="fully editable text with the Appearance panel"/></figure>
