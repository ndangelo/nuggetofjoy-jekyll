<h3><a href="https://www.theodinproject.com/lessons/foundations-elements-and-tags#elements-and-tags">Elements and Tags</a></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Almost all elements on an HTML page are just pieces of content wrapped in opening and closing HTML tags.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Opening tags tell the browser this is the start of an HTML element. They are comprised of a keyword enclosed in angle brackets&nbsp;<code>&lt;&gt;</code>. For example, an opening paragraph tag looks like this:&nbsp;<code>&lt;p&gt;</code>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Closing tags tell the browser where an element ends. They are almost the same as opening tags; the only difference is that they have a forward slash before the keyword. For example, a closing paragraph tag looks like this:&nbsp;<code>&lt;/p&gt;</code>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>A full paragraph element looks like this:</p>
<!-- /wp:paragraph -->

<!-- wp:image {"id":59373,"sizeSlug":"full","linkDestination":"none"} -->
<figure class="wp-block-image size-full"><img src="http://nuggetofjoy.com/wp-content/uploads/image-12.png" alt="" class="wp-image-59373"/></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>You can think of elements as containers for content. The opening and closing tags tell the browser what content the element contains. The browser can then use that information to determine how it should interpret and format the content.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>There are some HTML elements that do not have a closing tag. These elements often look like this:&nbsp;<code>&lt;br /&gt;</code>&nbsp;or&nbsp;<code>&lt;img/&gt;</code>, but some can also be used without the closing forward slash such as&nbsp;<code>&lt;br&gt;</code>&nbsp;or&nbsp;<code>&lt;img&gt;</code>. These are known as self-closing tags or empty elements because they don’t wrap any content. We will encounter a few of these in later lessons, but for the most part, elements will have both opening and closing tags.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>HTML has a&nbsp;<a href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element" target="_blank" rel="noreferrer noopener">vast list of predefined tags</a>&nbsp;that you can use to create all kinds of different elements. It is important to use the correct tags for content. Using the correct tags can have a big impact on two aspects of your sites: how they are ranked in search engines; and how accessible they are to users who rely on assistive technologies, like screen readers, to use the internet.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Using the correct elements for content is called semantic HTML. We will explore this in much more depth later on in the curriculum.</p>
<!-- /wp:paragraph -->
