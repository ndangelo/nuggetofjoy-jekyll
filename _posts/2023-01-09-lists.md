<h3><a href="https://www.theodinproject.com/lessons/foundations-lists#unordered-lists">Unordered Lists</a></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>If you want to have a list of items where the order doesn’t matter, like a shopping list of items that can be bought in any order, then you can use an unordered list.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Unordered lists are created using the&nbsp;<code>&lt;ul&gt;</code>&nbsp;element, and&nbsp;each item within the list is created using the list item element&nbsp;<code>&lt;li&gt;</code>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Each list item in an unordered list begins with a bullet point:</p>

<h3><a href="https://www.theodinproject.com/lessons/foundations-lists#ordered-lists">Ordered Lists</a></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>If you instead want to create a list of items where the order&nbsp;<em>does</em>&nbsp;matter, like step-by-step instructions for a recipe, or your top 10 favorite TV shows, then you can use an ordered list.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Ordered lists are created using the&nbsp;<code>&lt;ol&gt;</code>&nbsp;element. Each individual item in them is again created using the list item element&nbsp;<code>&lt;li&gt;</code>. However, each list item in an ordered list begins with a number instead:</p>
