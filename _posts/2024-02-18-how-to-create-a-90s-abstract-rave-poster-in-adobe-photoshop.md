<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-hk2u-how-to-set-up-a-new-photoshop-file">1.&nbsp;How to Set Up a New Photoshop File</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-h1yc-step-1"><strong>Step 1</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Let's start this rave flyer 90s-inspired design. In <strong>Photoshop</strong>, go to <strong>File > New</strong>. Name the document <em>Rave-Poster. </em>Set the <strong>Width</strong> to <strong>1270 px</strong> and <strong>Height</strong> to <strong>1600 px</strong>. Set the <strong>Resolution </strong>to <strong>72 Pixels/Inch</strong>. Click <strong>OK</strong>.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-1.jpg" alt="Create a new Photoshop file"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-z5o5-step-2"><strong>Step 2</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>In the&nbsp;<strong>Layers&nbsp;</strong>panel, click on&nbsp;<strong>Create a New Fill or Adjustment Layer &gt; Gradient&nbsp;</strong>to get some rave colors started. In the<strong>&nbsp;Gradient Fill</strong>&nbsp;window, select the&nbsp;<strong>Style&nbsp;</strong>to&nbsp;<strong>Linear&nbsp;</strong>and click on the&nbsp;<strong>Gradient</strong>&nbsp;swatch to set the colors.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Under&nbsp;<strong>Presets,&nbsp;</strong>select the&nbsp;<strong>Foreground to Background</strong>&nbsp;preset. Under&nbsp;<strong>Gradient Type,</strong>&nbsp;set the left color stop swatch to&nbsp;<code>#00a175</code>&nbsp;and the right color stop to&nbsp;<code>#0500e8</code>. Click&nbsp;<strong>OK.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-2.jpg" alt="Add a gradient fill layer with a linear style from color green to blue"/></figure>
<!-- /wp:image -->

<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-azei-how-to-create-the-background-lights-effect">2.&nbsp;How to Create the Background Lights Effect</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-pg1h-step-1"><strong>Step 1</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>On the&nbsp;<strong>Layers&nbsp;</strong>panel, create a new layer by pressing&nbsp;<strong>Shift-Command-N.&nbsp;</strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>On the toolbar, select the&nbsp;<strong>Brush Tool (B)</strong>.&nbsp;<strong>Right-click</strong>&nbsp;to set the brush<strong>&nbsp;Size</strong>&nbsp;to&nbsp;<strong>250 px</strong>&nbsp;and select a rounded brush with&nbsp;<strong>Hardness&nbsp;</strong>of&nbsp;<strong>0.&nbsp;</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-3.jpg" alt="Create a new layer and select the brush tool"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-1psh-step-2"><strong>Step 2</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>We'll add more rave colors. Using the color codes below, create single brush stamps by clicking on the document.</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul><!-- wp:list-item -->
<li>Orange:&nbsp;<code>#ff6600</code></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>Magenta:&nbsp;<code>#ff00df</code></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>Red:&nbsp;<code>#ff0055</code></li>
<!-- /wp:list-item --></ul>
<!-- /wp:list -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-4.jpg" alt="Using the brush tool use the colors orange magenta and red and create brush stamps over the new layer"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-wcdg-step-3"><strong>Step 3</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>While selecting the same layer, go to <strong>Filter > Blur > Motion Blur. </strong>In the <strong>Motion Blur</strong> window, check the <strong>Preview </strong>box. Set the <strong>Angle </strong>to <strong>-50</strong> and the <strong>Distance </strong>to <strong>1500 Pixels. </strong>Click <strong>OK.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Feel free to experiment with the settings. Changing the angle and distance will result in different outcomes.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-5.jpg" alt="Apply a motion blur filter on the brush stamps to create a light effect"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-hn3m-step-4"><strong>Step 4</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>You can repeat this section as many times as you like. Try making the brush size smaller or larger or choosing different rave colors. I added another layer with the same colors to add more dimension.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-6.jpg" alt="Repeat the action as many times youd like to create a dynamic background"/></figure>
<!-- /wp:image -->

<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-epll-how-to-create-the-dust-effect">3.&nbsp;How to Create the Dust Effect</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-g44m-step-1"><strong>Step 1</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>To create the dust effect, we need to create something similar to the steps above. Create a new layer on the&nbsp;<strong>Layers</strong>&nbsp;panel by pressing&nbsp;<strong>Shift-Command-N.</strong>&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Select the&nbsp;<strong>Brush Tool (B)</strong>&nbsp;and set the foreground color to&nbsp;<code>#aeaeae</code>.&nbsp;<strong>Right-click</strong>&nbsp;to set the Brush options. Set the&nbsp;<strong>Size</strong>&nbsp;to&nbsp;<strong>500 px</strong>&nbsp;and the&nbsp;<strong>Hardness&nbsp;</strong>to&nbsp;<strong>100%.&nbsp;</strong>Brush over the center of the page.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-7.jpg" alt="Create a new layer and using the brush tool and a color grey brush over the layer"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-s9aq-step-2"><strong>Step 2</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>While selecting the layer with the brush stroke, head over to&nbsp;<strong>Filter &gt; Blur &gt; Motion Blur.&nbsp;</strong>Depending on the&nbsp;<strong>Distance</strong>&nbsp;we set, we will either get a blur that is barely there or one that maintains the original shape we started with. I will maintain the&nbsp;<strong>Angle&nbsp;</strong>of&nbsp;<strong>-50&nbsp;</strong>and set the<strong>&nbsp;Distance&nbsp;</strong>to&nbsp;<strong>531.&nbsp;</strong>Click&nbsp;<strong>OK.&nbsp;</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-8.jpg" alt="Apply the motion blur filter"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-cqyi-step-3"><strong>Step 3</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>To create the dust effect, head over to&nbsp;<strong>Filter &gt; Noise &gt; Add Noise.&nbsp;</strong>Here, we can set the coarseness of the particles. We can always lower the opacity later to create a "barely there" look. Check the&nbsp;<strong>Preview&nbsp;</strong>box to see what the result will be. I will set the&nbsp;<strong>Amount&nbsp;</strong>to&nbsp;<strong>180%&nbsp;</strong>and the&nbsp;<strong>Distribution&nbsp;</strong>to&nbsp;<strong>Uniform.&nbsp;</strong>Click&nbsp;<strong>OK.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Select the dust particle layer on the Layers panel and lower the <strong>Opacity </strong>to <strong>35%.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-9.jpg" alt="Apply a noise filter on the same layer to create the particles and lower the opacity of the layer"/></figure>
<!-- /wp:image -->

<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-lxr2-how-to-edit-a-visually-interesting-image">4.&nbsp;How to Edit a Visually Interesting Image</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-1ger-step-1"><strong>Step 1</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Open the <a href="https://www.dropbox.com/scl/fi/h6p5qzn644ofx39v741u3/mask.jpg?rlkey=eyxq73sza2u4gzldwgzzdgczh&amp;dl=1">Scenic view of ruins and bronze statue in ancient Pompeii</a> in Photoshop. </p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>On the&nbsp;<strong>Layers&nbsp;</strong>panel,&nbsp;<strong>double-click</strong>&nbsp;on the&nbsp;<strong>Background&nbsp;</strong>layer to unlock it. The&nbsp;<strong>New Layer</strong>&nbsp;window option will open—rename the layer&nbsp;<em>Statue.&nbsp;</em>Click&nbsp;<strong>OK.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-10.jpg" alt="Open the statue image from Envato Elements in Photoshop and unlock the layer"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-8iz9-step-2"><strong>Step 2</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>On the<strong>&nbsp;Layers&nbsp;</strong>panel, add a&nbsp;<strong>Layer Mask&nbsp;</strong>to the&nbsp;<em>Statue&nbsp;</em>layer.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-11.jpg" alt="Add a layer mask to the statue image"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-94j9-step-3"><strong>Step 3</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Using the&nbsp;<strong>Brush Tool (B),&nbsp;</strong>set the foreground color to black. Start by brushing over the outside of the statue—in this case, we want to maintain only the statue to use on the&nbsp;<em>Rave-Poster&nbsp;</em>file.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Use the backslash <strong>(\) </strong>key to see the parts that have been masked. </p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-12.jpg" alt="Mask out the image leaving only the face of the statue"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-3d5i-step-4"><strong>Step 4</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Let’s crop the image to be easily manageable in the&nbsp;<em>Rave-Poster</em>&nbsp;file. In the toolbar, select the&nbsp;<strong>Crop Tool (C)&nbsp;</strong>and crop the image to just around the statue. Press&nbsp;<strong>Enter</strong>&nbsp;to proceed.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-13.jpg" alt="Crop the image to just around the statue"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-fw1c-step-5"><strong>Step 5</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p><strong>Right-click</strong>&nbsp;on the&nbsp;<em>Statue</em>&nbsp;layer and select&nbsp;<strong>Duplicate Layer.&nbsp;</strong>Under&nbsp;<strong>Destination &gt; Document</strong>, choose the&nbsp;<em>Rave-poster&nbsp;</em>file<em>.&nbsp;</em>Click&nbsp;<strong>OK.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-14.jpg" alt="Duplicate the layer onto the rave-poster file"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-jmwn-step-6"><strong>Step 6</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Head over to the <em>Rave-Poster </em>file. We need to resize and rotate the image. Select the <em>Statue </em>layer and press <strong>Command-T </strong>to <strong>Transform. </strong>Go to the option bar, and activate the<strong> Maintain Aspect Ratio</strong> button. Set the <strong>Width </strong>and <strong>Height</strong> to <strong>45%</strong> and the <strong>Rotation </strong>to <strong>-45 degrees.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-15.jpg" alt="Resize and rotate the image"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-ayoh-step-7"><strong>Step 7</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The advantage of working with Layer Masks is that we can hide and show parts of them without completely deleting them. In this case, I want to refine the statue by only keeping the face and masking out the neck area. Select the Layer Mask on the&nbsp;<em>Statue&nbsp;</em>layer and,&nbsp;using the&nbsp;<strong>Brush Tool (B)&nbsp;</strong>and black as a foreground color, start brushing the parts off. There is no right or wrong.&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Here, you can also hide the edges of the photo that are easy to miss when using Layer Masks and duplicating images. </p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-16.jpg" alt="Refine the masking on the statue image"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-84ip-step-8"><strong>Step 8</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Select the&nbsp;<em>Statue</em>&nbsp;layer,&nbsp;<em>not the layer mask linked to it.&nbsp;</em>Head over to&nbsp;<strong>Filter &gt; Distort &gt; Wave.&nbsp;</strong>In the&nbsp;<strong>Wave&nbsp;</strong>settings window, set the&nbsp;<strong>Type&nbsp;</strong>to&nbsp;<strong>Square,&nbsp;</strong>which means that the effect will divide the image into squares. Set the&nbsp;<strong>Number of Generators&nbsp;</strong>to&nbsp;<strong>20,&nbsp;</strong>the&nbsp;<strong>Wavelength&nbsp;</strong>to&nbsp;<strong>Min. 817&nbsp;</strong>and&nbsp;<strong>Max. 818, Amplitude&nbsp;</strong>to&nbsp;<strong>Min. 1&nbsp;</strong>and&nbsp;<strong>Max. 2,&nbsp;</strong>and finally the&nbsp;<strong>Scale&nbsp;</strong>to&nbsp;<strong>100%&nbsp;</strong>both&nbsp;<strong>Horizontal&nbsp;</strong>and&nbsp;<strong>Vertical.&nbsp;</strong>Click&nbsp;<strong>OK.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>If the statue covers the dust layer, feel free to enlarge it or move it around so that it's visible. </p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-17.jpg" alt="Apply the wave filter onto the statue layer"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-grq1-step-9"><strong>Step 9</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>In some cases, images don’t exactly match the background color we are working with, and it's necessary to find a way to make the image neutral. In this case, we will convert it to Black and White. On the <strong>Layers </strong>panel, click on <strong>Create a New Fill or Adjustment Layer > Black &amp; White. </strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-18.jpg" alt="Add a black and white adjustment layer"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-keyl-step-10"><strong>Step 10</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>If we want to have only the image in black and white, we must create a Clipping Mask. While holding down the <strong>Option </strong>key, hover between the <strong>Black &amp; White </strong>Adjustment Layer and the layer below, and click once you see the arrow pointing down. A Clipping Mask will apply the Adjustment Layer only to the layer underneath.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-19.jpg" alt="Create a clipping mask on the black and white layer to be applied only on the statue image"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-bvtp-step-11"><strong>Step 11</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>We can adjust the Brightness/Contrast if the poster looks somewhat dull. On the <strong>Layers </strong>panel, click on <strong>Create a New Fill or Adjustment Layer > Brightness/Contrast</strong>. In the <strong>Properties </strong>panel, we can adjust as much or as little as we want. There are advantages to tweaking the Brightness/Contrast this way instead of via <strong>Image > Adjustment. </strong>We can hide and show the layer and tweak the settings with the <strong>Properties </strong>panel. </p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-20.jpg" alt="Add an adjustment layer to tweak the brightness contrast of the overall file"/></figure>

<!-- wp:heading -->
<h2 class="wp-block-heading" id="toc-alyq-how-to-add-text-and-use-stylistic-alternates">5.&nbsp;How to Add Text and Use Stylistic Alternates</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-6jv4-step-1"><strong>Step 1</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The rave flyer 90s-inspired design is looking great so far. Now it's time for text. Select the Type Tool (B) in the toolbar and add the text, "SHADES OF ELECTRO FESTIVAL".<em> </em>Using the <strong>Type > Panel ></strong> <strong>Characters </strong>panel, set the font to <strong>Space Odyssey - Modern Sans Serif,</strong> the <strong>Size</strong> to <strong>140 pt,</strong> the <strong>Leading </strong>to<strong> 130 pt, </strong>and the <strong>Tracking </strong>to <strong>40.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-21.jpg" alt="Add text using the type tool"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-lilk-step-2"><strong>Step 2</strong></h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The font includes extended features on some letters that expand the width dramatically. In order to access these, you need to keep the&nbsp;<strong>Characters&nbsp;</strong>panel open. You can also access it by going to&nbsp;<strong>Type &gt; Panel &gt; Characters.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>In this case, we will only use some of the alternates to fit the width of the poster. While on the text layer, select the letters&nbsp;<strong>H</strong>&nbsp;and&nbsp;<strong>A,&nbsp;</strong>head over to the&nbsp;<strong>Characters&nbsp;</strong>panel, and click the&nbsp;<strong>Stylistic Alternate&nbsp;</strong>button to use the alternate. Change the color of the text to white.</p>
<!-- /wp:paragraph -->

<!-- wp:image {"align":"center"} -->
<figure class="wp-block-image aligncenter"><img src="https://cms-assets.tutsplus.com/cdn-cgi/image/width=850/uploads/users/2056/posts/31359/image/006-3-Abstract-Rave-Poster-22.jpg" alt="Using the characters panel activate the stylistic alternate button for the different letters"/></figure>
<!-- /wp:image -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="toc-7w1i-step-3"><strong>Step 3</strong></h3>
