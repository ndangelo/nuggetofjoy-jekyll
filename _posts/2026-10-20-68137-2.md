**Big idea:** CSS Grid is a two-dimensional layout system. It helps you organize content across both rows and columns. 
## 02 / Your first grid

Start with a container and six items. The container defines the layout; the items are the elements placed inside it.

`<div class="grid-container"> <div class="grid-item">One</div> <div class="grid-item">Two</div> <div class="grid-item">Three</div> <div class="grid-item">Four</div> <div class="grid-item">Five</div> <div class="grid-item">Six</div> </div>``.grid-container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 16px; } .grid-item { padding: 30px; background: #e5edff; border: 1px solid #b7c9f5; }`OneTwoThreeFourFiveSix
### display: grid

Turns the element into a grid container.

### repeat(3, 1fr)

Creates three equal-width columns.

### gap: 16px

Creates consistent space between grid items.

 
## 03 / Columns and the fr unit

The `grid-template-columns` property defines the columns. The `fr` unit distributes available space in fractions.

### Three equal columns

`grid-template-columns: 1fr 1fr 1fr;`111
### Two equal columns

`grid-template-columns: repeat(2, 1fr);`11
### Unequal columns

`grid-template-columns: 2fr 1fr;`2fr1fr**Tip:** `repeat(3, 1fr)` is a shorter way to write three equal columns. Use `minmax(0, 1fr)` when you need flexible tracks that can shrink without overflowing. 
## 04 / Rows and spacing

### Define rows

`grid-template-rows: 150px 200px;`This defines two explicit rows. Additional content may create implicit rows.

### Set the gap

`gap: 20px;`Sets both row and column gaps to 20 pixels.

### Different spacing

`row-gap: 24px; column-gap: 16px;`Use separate values when vertical and horizontal spacing need to differ.

For card layouts, let content determine row height when possible. Fixed row heights can cause text or images to overflow.

 
## 05 / Make an item span columns

A featured project can occupy two columns while the other cards occupy one.

`.featured { grid-column: span 2; }`Featured projectProject 2Project 3Project 4To span two rows instead, use `grid-row: span 2;`. Use spanning to establish hierarchy, not just decoration.

 
## 06 / Responsive Grid

This pattern lets the browser decide how many columns fit based on the available width.

`.grid-container { display: grid; grid-template-columns: repeat(auto-fit, minmax(220px, 1fr)); gap: 20px; }`
### auto-fit

Fits as many columns as the available space allows.

### minmax(220px, 1fr)

Each column aims to be at least 220px wide and can grow to share the available space.

### Responsive result

Wide screens show more columns; narrow screens show fewer.

Another approach is to use media queries when you want precise control at particular breakpoints.

## 08 / Troubleshooting

### CSS does not appear

Check that both files are in the same folder and that the stylesheet filename matches exactly.

### Grid overflows

Try `minmax(0, 1fr)` for flexible columns and check for long unbreakable content.

### Featured card looks odd on mobile

Reset `grid-column: auto` at the narrow-screen breakpoint.

### Spacing looks inconsistent

Use `gap` on the grid container rather than adding different margins to every card.
