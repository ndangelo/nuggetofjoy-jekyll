# Migration input

Upload the downloaded file `nuggetofjoy-jekyll-migration-draft.zip` into this folder using GitHub's **Add file → Upload files** interface. Do not upload the original 150 MB WordPress XML export here. After the ZIP is committed, run **Actions → Import WordPress migration draft → Run workflow**. The workflow imports published posts and non-homepage pages, copies the reports, and deliberately holds the original homepage back for a separate review. The ZIP is excluded from the generated site.
